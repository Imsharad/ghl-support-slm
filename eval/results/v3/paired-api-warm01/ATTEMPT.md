# Confounded partial benchmark — not a headline result

This first paired attempt overlapped the full CPU regression suite, including
real Qwen model inference. It was deliberately interrupted after recognizing
the contention. Raw warmups/measurements and original metadata are preserved;
there is no complete summary and no claim of comparable isolated performance.
The next benchmark must run after the regression suite completes and without
other agent-launched model workloads. Desktop background activity remains an
explicit limitation. No model answers from this development attempt are final
test evidence.
