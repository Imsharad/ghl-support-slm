# 6. Evaluation design

Primary: paired change in **human support-pass rate on 108 sealed challenge queries**. Sharad authors before outputs, hides model names, and randomizes answer order. Disclose sole-reviewer bias.

| Set | Size and role |
|---|---|
| Development | 54 authored scenarios plus 135 grouped validation rows; used for debugging and checkpoint choice. |
| Challenge | 54 fresh ordinary queries, two per assignment intent, plus 54 distinct hard scenarios: typos, anger, multiple requests, missing context, unsupported policy, off-topic requests. No paraphrase variants of one scenario counted as independent. |
| Bitext test | 270 queries, target ten per intent, sampled across distinct groups before outputs. If infeasible, use available groups and report smaller counts/missing intents. Judge all; human-check 54 selected in advance. |

A pass addresses all requests, gives sound next steps, admits missing facts, and uses helpful tone. Invented policy/status/actions or credential requests are critical failures. Correctness outranks style; “contact support” alone earns no pass. Supply scenario facts/acceptable actions. Bitext references are fallible.

Secondary: win/tie/loss, critical-error rate, intent/category pass rates, placeholder rate, answer length, empty/truncated answers, and serving speed. Do not headline reference overlap.

Judge: `meta-llama/Llama-3.1-8B-Instruct`, Meta Llama family; local [`llama3.1:8b-instruct-q4_K_M`](https://ollama.com/library/llama3.1:8b-instruct-q4_K_M), pinned digest. Expected [`LICENSE`](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct/blob/main/LICENSE): Llama 3.1 Community License; **TO-VERIFY offline** before pulling. Swap pair positions; preserve conflicting verdicts as “inconsistent.” Report human agreement. If access/runtime fails, retain human scoring and disclose reduced judge coverage.

Base/tuned: identical native chat template, system prompt, greedy decoding, 256 new-token cap, repetition penalty 1, same end token, same context limit. Judge: temperature 0, 192-token output cap, short structured verdict. Pin all settings; a seed alone does not guarantee matching outputs across runtimes.

Report counts, percentage-point difference, paired 95% bootstrap intervals using 2,000 scenario/group resamples, and effective group counts. Category tables are descriptive. Claim improvement only for challenge gain ≥5 points, interval excluding zero, without increased critical errors. Otherwise: inconclusive; lower tuned pass rate or more critical errors: negative. Bitext gains alone do not prove transfer. Intervals exclude reviewer bias and unknown-set uncertainty.
